# Module contract

**Status: designated home (stub).** This document is the canonical home for WiseKiosk's five-part
module contract. Until the FOUNDATIONS sunset (#42) graduates the contract prose into it, the
authoritative description lives in [`FOUNDATIONS.md` §6](../FOUNDATIONS.md#6-module-contract) — this
page records where that text will live and carries no independent normative weight of its own.

The contract's normative force is the requirements themselves: **SYS024** and **SRS033–SRS037** in
the [requirements tree](../requirements/), with the per-module test obligations in
[`TESTING.md`](../TESTING.md).
