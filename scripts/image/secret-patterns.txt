# The enumeration "secret material" resolves to, for
# SRS025<!-- No secret material in the published image -->. One Python regular expression per line;
# a blank line and a line beginning with # are not patterns. Matched against every byte of every
# layer, decoded as latin-1, by scripts/image/layer_secret_scan.py.
#
# Every pattern here is a secret *shape* — a marker, a prefix, or a value assigned to a name that
# says what it is. A bare high-entropy string is deliberately not a pattern: an image is full of
# content digests, certificate bodies and binary noise that no entropy threshold separates from a
# key, and a pattern that cannot pass on a clean image is not a check. The measurement behind that
# is in scripts/cases/check-image.md. Entropy is reached here only where it carries a name — the
# assignment patterns at the foot of the list.
#
# Two known gaps, stated rather than closed: a secret encoded other than as latin-1-decodable bytes
# (UTF-16, compressed, encrypted) is not seen, and a secret whose shape is not below is not
# described. The predicate is an enumeration this project maintains, not a decision procedure.

# Private key material, by its own header.
-----BEGIN (?:[A-Z0-9]+ )*PRIVATE KEY(?: BLOCK)?-----
PuTTY-User-Key-File-\d

# Issued credentials, by the prefix their issuer gives them.
\b(?:AKIA|ASIA|ABIA|ACCA)[0-9A-Z]{16}\b
\bgh[pousr]_[0-9A-Za-z]{36,}\b
\bglpat-[0-9A-Za-z_-]{20,}\b
\bnpm_[0-9A-Za-z]{36}\b
\bxox[abprs]-[0-9A-Za-z-]{10,}
\bAIza[0-9A-Za-z_-]{35}\b
\b(?:sk|rk)_(?:live|test)_[0-9A-Za-z]{16,}\b
\bsk-[0-9A-Za-z]{32,}\b

# A credential carried where it is used.
\b[a-z][a-z0-9+.-]*://[^\s:@/]+:[^\s:@/]+@
(?i)\bauthorization\s*[:=]\s*["']?(?:bearer|basic)\s+[0-9A-Za-z._~+/=-]{16,}

# A value assigned to a name that says it is a secret. No leading word boundary: `_` is a word
# character, so `\bpassword` does not match `db_password`, which is how the name is usually spelled.
(?i)aws_secret_access_key\s*[=:]\s*\S{40}
(?i)(?:api[_-]?key|secret[_-]?key|access[_-]?token|passwd|password)["']?\s*[=:]\s*["']?[0-9A-Za-z/+_=-]{16,}

# A secret's delivery variable, resolved to a value rather than left for the deployment to set
# (ADR 0024 rev 1).
\b[A-Z][A-Z0-9_]*_FILE\s*=\s*\S+
